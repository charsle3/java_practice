# Overview

The purpose of the program is to learn the Java language and practice it

The software is a simple trivia game that saves to and loads from a txt file, with conditional statements, logical comparisons, loops, classes, and built in classes like TreeMaps and HashMaps.

With the intent of practicing the language, the idea of a simple game attracted me.

[Software Demo Video](https://youtu.be/CVEnqQ82GCE)

# Development Environment

I used VS code with several quality of life Java extensions (like project manager and Language support)

Program was written in Java, importing the Scanner, File, FileWriter, TreeMap, HashMap, FileNotFoundException and IOException classes.
